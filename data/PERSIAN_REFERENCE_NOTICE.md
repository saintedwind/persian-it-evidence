# Persian public reference extracts

The 34 files in persian-reference/ are introductory plaintext extracts from Persian Wikipedia. The original six were retrieved on 2026-10-14; 28 additional articles were received on 2026-10-22. Individual receipt timestamps are in the manifest. Text authors: Persian Wikipedia contributors. Each file's title, immutable revision URL, contributor history link and SHA-256 are recorded in reference-manifest.json.

The checked-in plaintext strings are unchanged API extracts, not complete articles; MediaWiki removes page formatting and limits extraction to introductions. No images are included. No Wikipedia endorsement is claimed. Code and these licensed texts are separate works.

These introductions can contain outdated or incorrect statements. They are used to measure Persian source selection, not to establish operational policy or the correctness of technical advice.

The 28 additions include unchanged raw MediaWiki API receipts in reference-receipts/, with their own SHA-256 values. Disambiguation and missing pages were excluded, and original six source bytes were preserved. Categories and English search aliases are editorial metadata, separate from source text. Original API attribution, immutable revision URLs, history links and text licenses are retained.
